Project website for **MARC: Mechanism-Aware Reflective Correction for Articulated Object Code Generation**.

Authors: Xiong Yang, Jinkun Hao, Zijian Xiao, Zipeng Ye, Yuchen Xie, and Ran Yi.

The site includes the paper, overview video, recorded mechanism previews, and visual supplementary material.
