MARC — Visual Supplementary Material
====================================

Open index.html in a current desktop browser. No installation, server, network
connection, account, or plug-in is required. Keep all files in this folder together.

METHOD COMPARISON
20 reference objects, 7 methods: PhysX-Anything, URDF-Anything+, ArtLLM,
Instruct-Particulate, Procedura, Articraft (Kimi-K3), and MARC (Kimi-K3).

API ABLATION
Kimi-K3 and GPT-6, each with and without MARC. Kimi-K3 has 20 objects in each
configuration. GPT-6 has 19 in each; the planetary gearset is not provided.

CONTROLS
Choose an object in the left panel and a comparison tab at the top. Select
methods to show side by side. Each result card offers its available static
views and recorded motion sequences. Play all, scrub the shared slider, or
control each card independently. Click a render for an enlarged view.

INTERPRETATION
Sequence synchronization aligns normalized progress, not physical input values.
Tracks distinguish paired initial/actuated states, native control or physics
replays, single-joint pose samples, and authored kinematic animations.
Static geometry is retained when no usable motion output exists. Missing
outputs are not replaced with reference images or synthetic successful models.

Watermarks were removed from display copies of reference images using GPT Image.
Original inputs used for generation and evaluation are unchanged. Generated
output geometry and recorded motion were not edited with image generation.

All assets are local. The package contains no external scripts, fonts, analytics,
remote media, or absolute local file paths. More details appear in Viewing guide.
